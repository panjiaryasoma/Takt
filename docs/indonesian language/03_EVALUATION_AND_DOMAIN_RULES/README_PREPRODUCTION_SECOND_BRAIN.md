# Second Brain Pre-production

Folder ini adalah paket reasoning pre-production. Acuan utama tetap identifier teknis yang sama dengan canonical English docs.

## Invariant produk
- Decision support, bukan autonomous life scheduling.
- User mempertahankan consequential decision authority.
- Dual-path extraction mendahului canonical reconciliation.
- Field kritis canonical memiliki provenance.
- Conflict tetap terlihat sampai diselesaikan.
- Triage deterministik dan faktual.
- CP-SAT menghasilkan candidate allocation, bukan perintah.
- Recommendation menampilkan alasan, asumsi, alternatif, dan trade-off.
- Accepted commitment membutuhkan aksi eksplisit user.
- Monetization tidak boleh mengubah correctness.
- Data sintetis bukan bukti dunia nyata.
- Custom ML tidak boleh menjadi decision authority tanpa real held-out evaluation.

## Status
Pre-production cukup matang untuk contract/handoff work, tetapi dataset training final dan klaim real-world belum dikunci.
